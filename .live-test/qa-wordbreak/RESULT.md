## FP ไม่เสถียรระหว่างรอบ — ต้องรายงานทั้งสองรอบ

วัดด้วย prompt ตัวเดียวกัน (ถ้อยคำ `df02796`) สองรอบอิสระ:

| รอบ | recall (`bad_*`) | FP (`good_*`) | ใบ good ที่โดนผิด |
|---|---|---|---|
| รอบ A (30 คำตอบ) | 8/15 = 53% | 4/15 = 27% | good_1, good_3, good_5 |
| รอบ B (45 คำตอบ, รอบที่บันทึกไว้ข้างบน) | 8/15 = 53% | 1/15 = 7% | good_2 |
| รวม | **16/30 = 53%** | **5/30 = 17%** | **4 จาก 5 ใบ** เคยโดนผิดอย่างน้อยครั้งหนึ่ง |

recall นิ่งมากที่ 53% ทั้งสองรอบ ส่วน FP เหวี่ยงระหว่าง 7% กับ 27% — รอบเดียวจึงตัดสิน FP ไม่ได้
ตัวเลขรวม 17% อยู่ใต้เส้น 20% ก็จริง แต่ **4 ใน 5 ใบของ good เคยโดนตีตกผิด** เมื่อดูครบ 6 ครั้งต่อใบ
สรุปด้าน FP: ก้ำกึ่ง ยังสรุปไม่ได้ว่าปลอดภัย · สรุปด้าน recall: ไม่ผ่านชัดเจน

## สาเหตุที่พัง: โมเดลท่องคู่คำตัวอย่างในพรอมป์ ไม่ได้อ่านภาพ

## ผลวัด line-break ใน Chromium (หลักฐานตั้งต้นของแผนแก้ ZWSP)

**วิธีวัด 2 วิธีอิสระ ผลตรงกันเป๊ะทุกช่อง:**
1. ห่อทุกอักขระด้วย `<span>` แล้วดู `getBoundingClientRect().top` ที่กระโดด = จุดขึ้นบรรทัด
2. ใช้ `Range.setStart/setEnd` ทีละอักขระบน text node เดียว แล้วอ่าน `getClientRects()`
   (วิธีนี้ไม่แตะโครง DOM จึงไม่มีข้อกังขาว่า inline element ไปกวนการแบ่งคำของ ICU)

**สภาพแวดล้อม:** Chromium **150** (`Mozilla/5.0 … Chrome/150.0.0.0`) บน macOS ผ่าน Playwright MCP
กล่อง `.cap-phrase` คัดจาก `layout_multi_scene.html.tmpl:291-294` ตัวต่อตัว วัดได้ content width
= **836px** (`920 - 80 padding - 4 border`) ตรงกับ prod

**กลไก:** ZWSP (U+200B) เป็น **break opportunity** ไม่ใช่ break prohibition — UAX#14 จัดให้อยู่ใน
class **ZW** ซึ่งมีกฎว่า "ตัดได้หลัง ZW" (LB8) เท่านั้น ไม่มีกฎไหนบอกว่ามัน **ห้าม** ตัดที่อื่น
การประกบ ZWSP จึงแค่ *เพิ่ม* จุดที่ตัดได้ที่ขอบคำ แต่ **ไม่ได้ลบ** จุดที่ ICU ยอมให้ตัดข้างในคำทิ้ง
ส่วน WORD JOINER (U+2060) อยู่ class **WJ** ซึ่งห้ามตัดทั้งหน้าและหลัง จึงกันได้จริง

**ไม่ขัดกับเจตนาเดิมของโค้ด** — คอมเมนต์ที่ `internal/producer/thaiwrap.go:9-12` ระบุเองว่าเหตุผล
ที่ต้องประกบ ZWSP คือ *"คำที่ ICU ไม่รู้จัก 'ลาม' ไปทำให้คำไทยข้างเคียงถูกแบ่งผิดด้วย — 'แอดมินอยู่'
ถูกแบ่งเป็น 'แอด|มิ|นอ|ยู่' แล้วขึ้นบรรทัดกลางคำ 'อยู่' ทั้งที่ตัวปัญหาคือ 'แอดมิน'"*
คือกันการ **ลามไปคำข้างเคียง** ไม่ได้เคลมว่ากันการตัดในคำทับศัพท์เอง

```bash
# 1) เสิร์ฟจาก root ของ repo (Playwright MCP บล็อก file:) แล้วเปิดใน Chromium
python3 -m http.server 8731 --bind 127.0.0.1

# 2) ดึง prompt ตัวจริงจาก branch ที่รัน 066 แล้ว (prompts.json ไม่ commit — มันดริฟต์ตาม DB)

# 3) ยิงจริง (ต้องรันนอก sandbox — ต่อ api.kie.ai) แล้วสรุปเป็นตาราง
```

หมายเหตุ: `eval.py` ต้องตั้ง header `User-Agent` เอง — Cloudflare หน้า `api.kie.ai` บล็อก
`Python-urllib/3.x` ด้วย `error code: 1010` ทุก request (ฝั่ง Go ผ่านเพราะส่ง `Go-http-client/...`)
